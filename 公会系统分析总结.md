# 公会系统分析总结

## 一、公会系统的职责

公会系统主要解决六件事：

1. 管理公会的创建，包括公会名称、公告、会长等基本信息。
2. 处理公会申请，支持玩家申请加入公会，会长审批通过后成为成员。
3. 管理公会成员，包括成员列表、职位、加入时间、在线状态。
4. 处理公会离开和解散，普通成员可以离开，会长离开时解散公会。
5. 提供公会管理功能，包括任命副会长、罢免、转让会长、踢出成员。
6. 提供公会界面，显示公会信息、成员列表、申请列表、公会列表等。


## 二、整体实现方法

客户端与服务端的分工：

| `TGuild` ： 数据库实体，保存公会基本信息（Id、Name、LeaderID、LeaderName、Notice、CreateTime） |
| `TGuildMember` ： 数据库实体，保存公会成员信息（CharacterId、Name、Class、Level、Title、JoinTime、LastTime） |
| `TGuildApply` ： 数据库实体，保存公会申请记录（CharacterId、Name、Class、Level、Result、ApplyTime） |
| 服务端 `GuildManager` ： 单例管理器，管理所有公会，维护公会字典和公会名称集合 |
| 服务端 `Guild` ： 公会模型，包含公会数据、成员列表、申请处理、管理操作 |
| 服务端 `GuildService` ： 处理公会相关请求，包括创建、加入、离开、管理等 |
| 客户端 `GuildManager` ： 管理当前玩家的公会信息和成员信息 |
| 客户端 `GuildService` ： 发送公会请求，接收公会消息，处理响应 |
| `NGuildInfo` ： Protobuf 协议消息，传输公会信息（Id、GuildName、Notice、Leader、Members、Applies） |
| `UIGuild` ： 公会界面，显示公会信息、成员列表、公告等 |

公会系统与角色系统关联，通过 `Character.Guild` 和 `Character.Data.GuildId` 建立关联。

## 三、公会数据的定义

### 数据库实体 `TGuild` 保存公会基本信息

| `Id` ： 公会 ID（数据库主键） |
| `Name` ： 公会名称（唯一） |
| `LeaderID` ： 会长角色 ID |
| `LeaderName` ： 会长姓名 |
| `Notice` ： 公会公告 |
| `CreateTime` ： 创建时间 |
| `Members` ： 成员集合（ICollection<TGuildMember>） |
| `Applies` ： 申请集合（ICollection<TGuildApply>） |

### 数据库实体 `TGuildMember` 保存成员信息

| `Id` ： 数据库记录编号 |
| `CharacterId` ： 角色 ID |
| `Name` ： 角色姓名（冗余存储） |
| `Class` ： 职业（冗余存储） |
| `Level` ： 等级（冗余存储，上线时同步） |
| `Title` ： 职位（President 会长 / VicePresident 副会长 / None 普通成员） |
| `JoinTime` ： 加入时间 |
| `LastTime` ： 最后上线时间 |
| `GuildId` ： 所属公会 ID |

### 数据库实体 `TGuildApply` 保存申请记录

| `Id` ： 数据库记录编号 |
| `CharacterId` ： 申请者角色 ID |
| `Name` ： 申请者姓名 |
| `Class` ： 申请者职业 |
| `Level` ： 申请者等级 |
| `Result` ： 审批结果（None 待审批 / Accept 通过 / Reject 拒绝） |
| `ApplyTime` ： 申请时间 |
| `GuildId` ： 申请加入的公会 ID |

### 协议消息 `NGuildInfo` 传输公会信息

| `Id` ： 公会 ID |
| `GuildName` ： 公会名称 |
| `Notice` ： 公会公告 |
| `leaderId` ： 会长 ID |
| `leaderName` ： 会长姓名 |
| `createTime` ： 创建时间戳 |
| `memberCount` ： 成员数量 |
| `Members` ： 成员列表（List<NGuildMemberInfo>） |
| `Applies` ： 申请列表（List<NGuildApplyInfo>，仅会长可见） |

## 四、服务器启动时的公会初始化

--- 服务器启动时的公会加载流程
    GameServer 启动
    GuildService.Init() 调用 GuildManager.Instance.Init()
    遍历数据库中所有公会（DBService.Instance.Entities.Guilds）
    为每个公会创建 Guild 模型实例
    添加到 Guilds 字典（key = 公会 ID）
    添加公会名称到 GuildNames 集合（用于重名检查）
    设置公会时间戳


## 五、创建公会的流程

--- 创建公会的完整流程
    玩家点击创建公会
    打开 UIGuildPopCreate 界面
    输入公会名称和公告
    
    客户端 GuildService.SendGuildCreate(guildName, notice)
    发送 GuildCreateRequest 消息
        GuildName = 公会名称
        GuildNotice = 公会公告
    
    服务端 GuildService.OnGuildCreate 接收请求
    验证：
        检查角色是否已有公会（character.Guild != null）
        检查公会名称是否已存在（GuildManager.CheckNameExisted）
    调用 GuildManager.CreateGuild(name, notice, leader)
        创建 TGuild 数据库实体
        创建 Guild 模型实例
        添加会长为第一个成员（Title = President）
        设置 character.Guild 和 character.Data.GuildId
        保存数据库
        添加到公会管理器
    返回 GuildCreateResponse
    
    客户端接收响应
    GuildManager.Init(guildInfo) 初始化公会信息
    显示创建成功消息


### 服务端创建公会的核心代码

```csharp
internal bool CreateGuild(string name, string notice, Character leader)
{
    DateTime now = DateTime.Now;
    
    // 1. 创建数据库实体
    TGuild dbGuild = DBService.Instance.Entities.Guilds.Create();
    dbGuild.Name = name;
    dbGuild.Notice = notice;
    dbGuild.LeaderID = leader.Id;
    dbGuild.LeaderName = leader.Name;
    dbGuild.CreateTime = now;
    DBService.Instance.Entities.Guilds.Add(dbGuild);

    // 2. 创建 Guild 模型
    Guild guild = new Guild(dbGuild);
    
    // 3. 添加会长为第一个成员
    guild.AddMember(leader.Id, leader.Name, leader.Data.Class, leader.Data.Level, GuildTitle.President);
    
    // 4. 关联角色和公会
    leader.Guild = guild;
    DBService.Instance.Save();
    leader.Data.GuildId = dbGuild.Id;
    DBService.Instance.Save();
    
    // 5. 添加到公会管理器
    this.AddGuild(guild);

    return true;
}
```

## 六、申请加入公会的流程

--- 申请加入公会的完整流程
    玩家打开公会列表界面
    选择要加入的公会
    点击申请加入按钮
    
    客户端 GuildService.SendGuildJoinRequest(guildId)
    发送 GuildJoinRequest 消息
        Apply.GuildId = 公会 ID（其他字段由服务端填充）
    
    服务端 GuildService.OnGuildJoinRequest 接收请求
    获取公会实例
    填充申请信息（characterId、Name、Class、Level）
    调用 guild.JoinApply(apply)
        检查是否已申请过（防止重复申请）
        创建 TGuildApply 数据库实体
        添加到 guild.Data.Applies 集合
        保存数据库
        更新公会时间戳
    如果会长在线：
        将申请请求转发给会长（leader.Session.Response.guildJoinReq）
    
    会长收到 GuildJoinRequest 消息
    客户端 GuildService.OnGuildJoinRequest 显示确认对话框
    会长选择接受或拒绝
    
    客户端 GuildService.SendGuildJoinResponse(accept, request)
    发送 GuildJoinResponse 消息
        Apply.Result = Accept / Reject
    
    服务端 GuildService.OnGuildJoinResponse 接收响应
    调用 guild.JoinAppove(apply)
        查找申请记录
        更新 Result 字段
        如果接受：调用 AddMember 添加成员
        保存数据库
        更新公会时间戳
    发送成功消息给申请者
    
    申请者客户端接收响应
    显示加入成功消息
    通过后处理机制同步公会信息


### 公会申请审批的核心代码

```csharp
public bool JoinAppove(NGuildApplyInfo apply)
{
    // 1. 查找待审批的申请记录
    var oldApply = this.Data.Applies.FirstOrDefault(v => v.CharacterId == apply.characterId && v.Result == 0);
    if(oldApply == null)
    {
        return false;
    }
    
    // 2. 更新审批结果
    oldApply.Result = (int)apply.Result;
    
    // 3. 如果接受，添加为公会成员
    if(apply.Result == ApplyResult.Accept)
    {
        this.AddMember(apply.characterId, apply.Name, apply.Class, apply.Level, GuildTitle.None);
    }
    
    DBService.Instance.Save();
    this.timestamp = TimeUtil.timestamp;
    return true;
}
```

## 七、离开公会的流程

--- 离开公会的完整流程
    玩家点击离开公会按钮
    显示确认对话框
    
    客户端 GuildService.SendGuildLeaveRequest()
    发送 GuildLeaveRequest 消息
    
    服务端 GuildService.OnGuildLeave 接收请求
    验证角色是否有公会
    如果是会长：
        调用 guild.Disband() 解散公会
            遍历所有成员，调用 RemoveMember
            从数据库中删除所有成员和申请记录
            清除所有成员的 GuildId
            返回成员 ID 列表
        调用 GuildManager.DisbandGuild 从管理器中移除公会
        通知所有在线成员公会已解散
    如果是普通成员：
        调用 guild.Leave(characterId)
            查找成员记录
            调用 RemoveMember 删除成员
            从数据库删除成员和申请记录
            清除角色的 GuildId 和 Guild 引用
    保存数据库
    返回 GuildLeaveResponse
    
    客户端接收响应
    GuildManager.Init(null) 清空公会信息
    显示离开成功消息


### 离开公会的核心代码

```csharp
private void OnGuildLeave(NetConnection<NetSession> sender, GuildLeaveRequest request)
{
    Character character = sender.Session.Character;
    sender.Session.Response.guildLeave = new GuildLeaveResponse();

    if (character == null || character.Guild == null)
    {
        sender.Session.Response.guildLeave.Result = Result.Failed;
        sender.Session.Response.guildLeave.Errormsg = "你当前没有公会";
        sender.SendResponse();
        return;
    }

    var guild = character.Guild;
    var memberIds = new List<int>();

    if (character.Id == guild.Data.LeaderID)
    {
        // 会长离开：解散公会
        memberIds = guild.Disband();
        GuildManager.Instance.DisbandGuild(guild.Data);
    }
    else if (!guild.Leave(character.Id))
    {
        // 普通成员离开
        sender.Session.Response.guildLeave.Result = Result.Failed;
        sender.Session.Response.guildLeave.Errormsg = "你不是该公会成员";
        sender.SendResponse();
        return;
    }
    else
    {
        memberIds.Add(character.Id);
    }

    DBService.Instance.Save();
    sender.Session.Response.guildLeave.Result = Result.Success;
    sender.SendResponse();

    // 通知其他在线成员
    if (character.Id == guild.Data.LeaderID)
    {
        foreach (var memberId in memberIds)
        {
            if (memberId == character.Id)
                continue;

            var memberSession = SessionManager.Instance.GetSession(memberId);
            if (memberSession == null)
                continue;

            memberSession.Session.Response.guildLeave = new GuildLeaveResponse();
            memberSession.Session.Response.guildLeave.Result = Result.Success;
            memberSession.SendResponse();
        }
    }
}
```

## 八、公会管理功能

公会管理功能通过 `GuildAdminCommand` 实现：

| `Promote` ： 任命副会长 |
| `Depost` ： 罢免（降为普通成员） |
| `Transfer` ： 转让会长 |
| `Kickout` ： 踢出公会 |

### 管理操作的执行

```csharp
internal void ExecuteAdmin(GuildAdminCommand command, int targetId, int sourceId)
{
    var target = GetDbMember(targetId);
    var source = GetDbMember(sourceId);
    
    switch (command)
    {
        case GuildAdminCommand.Promote:
            // 任命副会长
            target.Title = (int)GuildTitle.VicePresident;
            break;
            
        case GuildAdminCommand.Depost:
            // 罢免
            target.Title = (int)GuildTitle.None; 
            break;
            
        case GuildAdminCommand.Transfer:
            // 转让会长
            target.Title = (int)GuildTitle.President;
            source.Title = (int)GuildTitle.None;
            this.Data.LeaderID = targetId;
            this.Data.LeaderName = target.Name;
            break;
            
        case GuildAdminCommand.Kickout:
            // 踢出公会
            this.Leave(targetId);
            break;
    }
    
    DBService.Instance.Save();
    timestamp = TimeUtil.timestamp;
}
```

### 管理权限验证

服务端在执行管理操作前验证权限：

```csharp
private void OnGuildAdmin(NetConnection<NetSession> sender, GuildAdminRequest message)
{
    Character character = sender.Session.Character;
    
    // 验证是否有公会
    if(character.Guild == null)
    {
        sender.Session.Response.guildAdmin.Result = Result.Failed;
        sender.Session.Response.guildAdmin.Errormsg = "你没公会不要乱来";
        sender.SendResponse();
        return;
    }
    
    // 验证是否有管理权限
    TGuildMember DBcharacter = DBService.Instance.Entities.GuildMembers.FirstOrDefault(v => v.Id == character.Id);
    if (DBcharacter != null && DBcharacter.Title == (int)GuildTitle.None)
    {
        sender.Session.Response.guildAdmin.Result = Result.Failed;
        sender.Session.Response.guildAdmin.Errormsg = "你还没有权限修改";
        sender.SendResponse();
        return;
    }
    
    // 执行管理操作
    character.Guild.ExecuteAdmin(message.Command, message.Target, character.Id);
    
    // 通知目标玩家（如果在线）
    var target = SessionManager.Instance.GetSession(message.Target);
    if(target != null)
    {
        target.Session.Response.guildAdmin = new GuildAdminResponse();
        target.Session.Response.guildAdmin.Result = Result.Success;
        target.Session.Response.guildAdmin.Command = message;
        target.SendResponse();
    }
    
    sender.Session.Response.guildAdmin.Result = Result.Success;
    sender.SendResponse();
}
```

## 九、公会信息的后处理机制

服务端 `Guild.PostProcess` 实现公会信息的自动同步：

```csharp
public void PostProcess(Character from, NetMessageResponse message)
{
    if(message.Guild == null)
    {
        message.Guild = new GuildResponse();
        message.Guild.Result = Result.Success;
        message.Guild.guildInfo = this.GuildInfo(from);
    }
}
```

`GuildInfo(from)` 收集公会完整信息：

```csharp
public NGuildInfo GuildInfo(Character from)
{
    NGuildInfo info = new NGuildInfo()
    {
        Id = this.Id,
        GuildName = this.Name,
        Notice = this.Data.Notice,
        leaderId = this.Data.LeaderID,
        leaderName = this.Data.LeaderName,
        createTime = (long)TimeUtil.GetTimestamp(this.Data.CreateTime),
        memberCount = this.Data.Members.Count,
    };
    
    if (from != null)
    {
        // 添加成员列表
        info.Members.AddRange(GetMemberInfos());
        
        // 如果是会长，添加申请列表
        if (from.Id == this.Data.LeaderID)
            info.Applies.AddRange(GetApplyInfos());
    }
    
    return info;
}
```

关键特性：

1. 在线成员从 `CharacterManager` 获取实时信息，离线成员使用数据库冗余数据。
2. 只有会长能看到申请列表。
3. 公会信息变化时更新 `timestamp`，触发后处理。

## 十、公会列表的获取

玩家可以查看所有公会列表，选择要加入的公会：

```csharp
private void OnGuildList(NetConnection<NetSession> sender, GuildListRequest request)
{
    Character character = sender.Session.Character;
    sender.Session.Response.guildList = new GuildListResponse();
    
    // 获取所有公会信息
    sender.Session.Response.guildList.Guilds.AddRange(GuildManager.Instance.GetGuildsInfo());
    sender.Session.Response.guildList.Result = Result.Success;
    sender.SendResponse();
}
```

`GetGuildsInfo()` 返回所有公会的基本信息（不包含成员列表和申请列表）：

```csharp
public List<NGuildInfo> GetGuildsInfo()
{
    List<NGuildInfo> result = new List<NGuildInfo>();
    foreach(var kv in this.Guilds)
    {
        result.Add(kv.Value.GuildInfo(null)); // 传入 null，不返回成员和申请
    }
    return result;
}
```
