# 聊天系统分析总结

## 一、聊天系统的职责

聊天系统主要解决六件事：

1. 支持多种聊天频道，包括本地、世界、队伍、公会、私聊、系统公告。
2. 管理聊天消息的存储和分发，服务端按频道和范围存储消息。
3. 实现私聊功能，支持点对点的实时消息传递。
4. 采用增量拉取机制，客户端只拉取新消息，避免重复传输。
5. 提供聊天界面，支持频道切换、消息显示、超链接点击、发送消息。
6. 支持消息格式化，不同频道使用不同颜色，玩家姓名可点击。


## 二、整体实现方法

客户端与服务端的分工：

| 服务端 `ChatManager` ： 单例管理器，按频道存储所有聊天消息（System、World、Local、Team、Guild） |
| 服务端 `Chat` ： 角色聊天模型，记录各频道的拉取索引，通过后处理机制推送新消息 |
| 服务端 `ChatService` ： 处理聊天请求，验证私聊目标，将消息添加到对应频道 |
| 客户端 `ChatManager` ： 管理本地聊天消息，按频道分类存储，支持频道过滤和切换 |
| 客户端 `ChatService` ： 发送聊天请求，接收聊天响应，更新本地消息列表 |
| `ChatMessage` ： 聊天消息结构（Channel、FromId、FromName、ToId、ToName、Message、Time） |
| `UIChat` ： 聊天界面，支持频道切换、消息显示、超链接点击、发送消息 |

聊天系统与队伍、公会系统关联，根据角色的队伍和公会推送相关频道消息。

## 三、聊天频道的定义

### 协议枚举 `ChatChannel` 定义频道类型

| `Local` ： 本地频道（同地图玩家可见） |
| `World` ： 世界频道（全服玩家可见） |
| `System` ： 系统频道（系统公告） |
| `Private` ： 私聊频道（玩家对玩家） |
| `Team` ： 队伍频道（队伍成员可见） |
| `Guild` ： 公会频道（公会成员可见） |

### 客户端本地频道 `LocalChannel`

客户端使用 `LocalChannel` 枚举管理显示和发送频道：

| `All` ： 综合频道（显示所有消息） |
| `Local` ： 本地频道 |
| `World` ： 世界频道 |
| `Team` ： 队伍频道 |
| `Guild` ： 公会频道 |
| `Private` ： 私聊频道 |

### 频道过滤器

客户端使用 `ChannelFilter` 数组定义每个本地频道显示哪些协议频道的消息：

```csharp
private ChatChannel[] ChannelFilter = new ChatChannel[6]
{
    ChatChannel.Local | ChatChannel.World | ChatChannel.Guild | ChatChannel.Team | ChatChannel.Private | ChatChannel.System, // All 综合
    ChatChannel.Local,    // Local 只显示本地
    ChatChannel.World,    // World 只显示世界
    ChatChannel.Team,     // Team 只显示队伍
    ChatChannel.Guild,    // Guild 只显示公会
    ChatChannel.Private,  // Private 只显示私聊
};
```

## 四、聊天消息的数据结构

`ChatMessage` 定义聊天消息：

| `Channel` ： 频道类型（ChatChannel 枚举） |
| `FromId` ： 发送者角色 ID |
| `FromName` ： 发送者姓名 |
| `ToId` ： 接收者角色 ID（私聊专用） |
| `ToName` ： 接收者姓名（私聊专用） |
| `Message` ： 消息内容 |
| `Time` ： 发送时间戳 |

## 五、服务端聊天消息的存储

服务端 `ChatManager` 按频道分类存储消息：

```csharp
public List<ChatMessage> System = new List<ChatMessage>();                     // 系统消息
public List<ChatMessage> World = new List<ChatMessage>();                      // 世界消息
public Dictionary<int, List<ChatMessage>> Local = new Dictionary<int, List<ChatMessage>>();   // 本地消息（key = 地图 ID）
public Dictionary<int, List<ChatMessage>> Team = new Dictionary<int, List<ChatMessage>>();    // 队伍消息（key = 队伍 ID）
public Dictionary<int, List<ChatMessage>> Guild = new Dictionary<int, List<ChatMessage>>();   // 公会消息（key = 公会 ID）
```

存储特性：

1. 系统和世界消息：全局单一列表，所有玩家共享。
2. 本地消息：按地图 ID 分组，同地图玩家共享。
3. 队伍消息：按队伍 ID 分组，同队伍成员共享。
4. 公会消息：按公会 ID 分组，同公会成员共享。
5. 私聊消息：不存储在服务端，直接转发给目标玩家。

## 六、发送聊天消息的流程

--- 发送聊天消息的完整流程
    玩家在聊天界面输入消息
    选择发送频道（本地、世界、队伍、公会、私聊）
    点击发送按钮
    
    客户端 ChatService.SendChat(channel, content, toId, toName)
    发送 ChatRequest 消息
        Message.Channel = 频道类型
        Message.Message = 消息内容
        Message.ToId = 私聊目标 ID（私聊专用）
        Message.ToName = 私聊目标姓名（私聊专用）
    
    服务端 ChatService.OnChat 接收请求
    如果是私聊频道：
        查找目标玩家 Session
        如果不在线：返回错误消息
        如果在线：
            填充 FromId 和 FromName
            发送消息给目标玩家
            发送消息给发送者（回显）
    如果是其他频道：
        调用 ChatManager.AddMessage(character, message)
            填充 FromId、FromName、Time
            根据频道类型添加到对应存储
        返回成功响应
    
    通过后处理机制推送新消息给相关玩家
    客户端接收 ChatResponse
    ChatService.OnChat 处理响应
        按频道类型添加消息到本地存储
        触发 OnChat 事件刷新界面


### 服务端处理聊天请求的核心代码

```csharp
private void OnChat(NetConnection<NetSession> sender, ChatRequest request)
{
    Character character = sender.Session.Character;
    
    if(request.Message.Channel == ChatChannel.Private)
    {
        // 处理私聊
        var chatTo = SessionManager.Instance.GetSession(request.Message.ToId);
        if(chatTo == null)
        {
            // 目标不在线
            sender.Session.Response.Chat = new ChatResponse();
            sender.Session.Response.Chat.Result = Result.Failed;
            sender.Session.Response.Chat.Errormsg = "对方不在线";
            sender.Session.Response.Chat.privateMessages.Add(request.Message);
            sender.SendResponse();
        }
        else
        {
            // 目标在线，转发消息
            if(chatTo.Session.Response.Chat == null)
            {
                chatTo.Session.Response.Chat = new ChatResponse();
            }
            request.Message.FromId = character.Id;
            request.Message.FromName = character.Name;
            chatTo.Session.Response.Chat.Result = Result.Success;
            chatTo.Session.Response.Chat.privateMessages.Add(request.Message);
            chatTo.SendResponse();

            // 回显给发送者
            if(sender.Session.Response.Chat == null)
            {
                sender.Session.Response.Chat = new ChatResponse();
            }
            sender.Session.Response.Chat.Result = Result.Success;
            sender.Session.Response.Chat.privateMessages.Add(request.Message);
            sender.SendResponse();
        }
    }
    else
    {
        // 处理其他频道
        sender.Session.Response.Chat = new ChatResponse();
        sender.Session.Response.Chat.Result = Result.Success;
        ChatManager.Instance.AddMessage(character, request.Message);
        sender.SendResponse();
    }
}
```

## 七、聊天消息的增量拉取机制

服务端采用 增量拉取 机制，避免重复传输消息：

### 角色聊天模型记录拉取索引

```csharp
class Chat
{
    Character Owner;

    // 当前聊天记录拉到第几条了
    public int localIdx;
    public int worldIdx;
    public int systemIdx;
    public int teamIdx;
    public int guildIdx;
}
```

### 后处理机制推送新消息

```csharp
public void PostProcess(NetMessageResponse message)
{
    if(message.Chat == null)
    {
        message.Chat = new ChatResponse();
        message.Chat.Result = Result.Success;
    }
    
    // 拉取本地消息（从 localIdx 开始）
    this.localIdx = ChatManager.Instance.GetLocalMessage(this.Owner.Info.mapId, this.localIdx, message.Chat.localMessages);
    
    // 拉取世界消息
    this.worldIdx = ChatManager.Instance.GetWorldMessage(this.worldIdx, message.Chat.worldMessages);
    
    // 拉取系统消息
    this.systemIdx = ChatManager.Instance.GetSystemMessage(this.systemIdx, message.Chat.systemMssages);
    
    // 拉取队伍消息
    if(this.Owner.Team != null)
    {
        this.teamIdx = ChatManager.Instance.GetTeamMessage(this.Owner.Team.Id, this.teamIdx, message.Chat.teamMessages);
    }
    
    // 拉取公会消息
    if(this.Owner.Guild != null)
    {
        this.guildIdx = ChatManager.Instance.GetGuildMessage(this.Owner.Guild.Id, this.guildIdx, message.Chat.guildMessages);
    }
}
```

### 获取新消息的逻辑

```csharp
private int GetNewMessages(int idx, List<ChatMessage> result, List<ChatMessage> messages)
{
    if(idx == 0)
    {
        // 首次拉取，限制最大数量
        if(messages.Count > GameDefine.MaxChatRecoredNums)
        {
            idx = messages.Count - GameDefine.MaxChatRecoredNums; // 只拉取最近 30 条
        }
    }

    // 从 idx 开始拉取所有新消息
    for(; idx < messages.Count; idx++)
    {
        result.Add(messages[idx]);
    }
    
    return idx; // 返回新的索引位置
}
```

关键特性：

1. 每次只拉取 `idx` 之后的新消息。
2. 首次拉取最多 30 条历史消息（`MaxChatRecoredNums = 30`）。
3. 后处理机制在每次响应时自动推送新消息。

### 添加消息到本地存储

```csharp
public void AddMessages(ChatChannel channel, List<ChatMessage> messages)
{
    // 遍历所有本地频道
    for(int ch = 0; ch < 6; ch++)
    {
        // 检查本地频道的过滤器是否包含协议频道
        if ((this.ChannelFilter[ch] & channel) == channel)
        {
            this.Messages[ch].AddRange(messages);
        }
    }
    
    // 触发 UI 刷新
    if(this.OnChat != null)
        this.OnChat();
}
```

例如：世界频道的消息会被添加到 `All` 和 `World` 两个本地频道。

### 消息格式化

```csharp
private string FormatMessage(ChatMessage message)
{
    switch (message.Channel)
    {
        case ChatChannel.Local:
            return string.Format("[本地]{0}{1}", FormatFromPlayer(message), message.Message);
        case ChatChannel.World:
            return string.Format("<color=cyan>[世界]{0}{1}</color>", FormatFromPlayer(message), message.Message);
        case ChatChannel.System:
            return string.Format("<color=red>[系统]{0}</color>", message.Message);
        case ChatChannel.Private:
            return string.Format("<color=magenta>[私聊]{0}{1}</color>", FormatFromPlayer(message), message.Message);
        case ChatChannel.Team:
            return string.Format("<color=green>[队伍]{0}{1}</color>", FormatFromPlayer(message), message.Message);
        case ChatChannel.Guild:
            return string.Format("<color=blue>[公会]{0}{1}</color>", FormatFromPlayer(message), message.Message);
    }
    return "";
}
```

### 玩家姓名超链接

```csharp
private string FormatFromPlayer(ChatMessage message)
{
    if(message.FromId == User.Instance.CurrentCharacter.Id)
    {
        return "<a name=\"\" class=\"player\">[我]</a>";
    }
    else
    {
        // 生成超链接：<a name="c:角色ID:姓名" class="player">[姓名]</a>
        return string.Format("<a name=\"c:{0}:{1}\" class=\"player\">[{1}]</a>", message.FromId, message.FromName);
    }
}
```

点击玩家姓名触发超链接点击事件：

```csharp
public void OnClickChatLink(HyperText text, HyperText.LinkInfo link)
{
    if(string.IsNullOrEmpty(link.Name))
        return;
    
    // 解析超链接：c:1001:name
    if(link.Name.StartsWith("c:"))
    {
        string[] strs = link.Name.Split(":".ToCharArray());
        UIPopChar menu = UIManager.Instance.Show<UIPopChar>();
        menu.targetId = int.Parse(strs[1]);
        menu.targetName = strs[2];
    }
}
```

点击后弹出角色菜单，可以查看资料、发起私聊、添加好友等。

## 十、发送频道的切换和验证

### 切换发送频道

```csharp
public bool SetSendChannel(LocalChannel channel)
{
    if(channel == LocalChannel.Team)
    {
        if(User.Instance.TeamInfo == null)
        {
            this.AddSystemMessage("你没有加入任何队伍");
            return false;
        }    
    }
    if(channel == LocalChannel.Guild)
    {
        if(User.Instance.CurrentCharacter.Guild == null)
        {
            this.AddSystemMessage("你还没有公会");
            return false;
        }
    }
    this.sendChannel = channel;
    return true;
}
```
